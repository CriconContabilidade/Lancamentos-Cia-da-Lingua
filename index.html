Cadastro — Categorias (planilha Contas Pagas)
De-para de palavra-chave (coluna Fornecedor da planilha) → conta de débito fixa (o crédito é sempre a conta banco). "Período" define o mês usado no histórico: Atual = mês do pagamento, Anterior = mês anterior ao pagamento. Todas as linhas do mesmo fornecedor no arquivo (boleto, juros, multa etc.) são somadas em um único lançamento. Marque "Ignorar" para excluir por completo (ex. FGTS/INSS/IRRF/Simples). Use "Lançamento automático" para uma segunda linha que sempre acompanha (ex. Cricon: honorários a pagar).
Formato de cada item: {keywords:[...], conta:345, periodo:"anterior"|"atual", hist:"...{MM}/{YYYY}...", ignorar:false}. Para o lançamento automático (ex. Cricon), acrescente companion:{conta:335, contraConta:222, hist:"...{MM}/{YYYY}...", dataUltimoDiaMesPagamento:true} — a data desse segundo lançamento vira o último dia do mês do pagamento.
Cadastro — Padrões do Extrato Bancário
Nomes/históricos que devem ser ignorados por completo no extrato da conta corrente (já são lançados via a planilha de Contas Pagas, ou estão fora do escopo desta ferramenta). O que não bate com nenhuma regra abaixo vira uma linha só com a conta banco preenchida, para completar à mão (ex. recebimentos de clientes).
Empréstimo à sócia Lisiane Rossi é direcional (mesma conta muda de lado conforme sai ou entra dinheiro). As tarifas bancárias são padrões simples (débito/crédito fixos).
